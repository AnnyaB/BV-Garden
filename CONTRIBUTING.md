# Contributing

BV-Garden is an educational browser game. Preserve its 20-chapter progression, no-repeat question history, Stella and Tonitrus awards, explorer position, camera and sound behavior.

1. Make a focused feature branch.
2. Edit the appropriate `src/` file, preserving ordering and globals.
3. Run `npm run build`, then inspect the `index.html` diff.
4. Run `npm test` and `npm run build:check` before committing.
5. For changes affecting interactions, additionally test keyboard, touch, narrow screens, unfinished quiz recovery, tenth-bolt resets and audio activation in real browsers.
6. Review scientific MCQ explanations, distractors, novelty and duplicates. Do not add unverified claims of solved world-model research.
7. Do not commit API keys, credentials, sensitive data or unlicensed external assets.

Unrestricted browser game anti-cheating is not possible: local question answers can be inspected, and no-repeat history lasts only while browser storage survives.
