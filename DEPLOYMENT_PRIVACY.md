# Deployment and privacy — please read before enabling Pages

**Current intent:** keep `AnnyaB/BV-Garden` private. The repository can store and version the complete playable game privately. That is *not* the same as publishing a privately viewable website.

GitHub's published documentation warns that a GitHub Pages website is publicly accessible even if the underlying repository is private. Genuine access-restricted Pages websites are a GitHub Enterprise Cloud organisational feature, not a private-personal-repository switch. Do not enable Pages or an automatic publishing workflow for this personal private repository unless the owner explicitly accepts a **public** game site, or independently confirms an access-restricted supported host.

To play while keeping privacy:
1. Open `index.html` after downloading it from the authenticated private repository, or use the same file in a private local browser. The HTML embeds sprites and gameplay logic and requires no paid API or server.
2. For maintainable development, use `research-garden-source.zip` locally; it includes individual files and documentation.
3. For private sharing, grant a specific trusted collaborator repository read access or use a separately authenticated private hosting product. File/repository access does not automatically provide a runnable website.
